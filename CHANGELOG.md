# Changelog

## v1.0.0

First public release of JellyGlance Companion for Android.

- Sign in with your JellyGlance account (password or Jellyfin Quick Connect).
- Home, Streams, Requests, Activity, Admin and Me tabs, with the JellyGlance themes and branding.
- Streams: send messages, stop (with a reason), pause/resume via a linked Jellyfin.
- Requests: discover, request, and manage the queue (bulk approve/decline/retry, edit, issues, rules with per-person limits).
- Statistics: Overview, Recap, Taste map, Up next, Library health, Streams and Devices.
- Admin: tasks, downloads, webhooks, integrations, backups, invites, devices, plugins, Repair hub, Jellyfin scheduled tasks, logs, API keys, library tracking and activity monitor.
- Title pages with ratings, seasons/episodes, history and "Open in Jellyfin app".
- Widgets (at a glance, Now playing, Pending requests, Server health), Quick Settings tile, notifications with Approve/Decline, Share to JellyGlance, add to calendar, app lock, tablet side rail, offline cache.
- In-app updates from GitHub Releases with checksum verification.
